# 架构决策记录 (Decision Log)

> 记录重要的技术决策及其理由。遇到"为什么这样做"时查阅。

---

## 模板

```markdown
### DEC-XXX: [决策标题]

**日期**: YYYY-MM-DD
**状态**: 已决定 / 已废弃 / 讨论中
**决策者**: [谁做的决定]

**背景**: [什么情况下需要做这个决定]

**选项**:
1. [方案 A] — 优点：... / 缺点：...
2. [方案 B] — 优点：... / 缺点：...

**决定**: 选择方案 [X]

**理由**: [为什么选这个]

**后果**: [这个决定会带来什么影响]
```
