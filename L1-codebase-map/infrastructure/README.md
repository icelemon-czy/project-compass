# 基础设施层

> 本文件夹文档化跨功能的底层架构和基础设施。
> **加载时机**：当任务涉及框架基类、配置系统、插件机制、通用工具时加载。
>
> 📂 **本文件夹结构**（按实际项目调整）：
> - `README.md` — 基础设施索引 + 导航（**先读这个**）
> - `[组件名].md` — 每个基础设施组件一个文件

## 架构全景

```
[如:
  功能层（features/*）
    ↓ 使用
  框架基类（BaseController, BaseService）
    ↓ 依赖
  配置系统（ConfigLoader → 环境变量 + 配置文件）
    ↓ 被
  插件系统（PluginHost → 加载/卸载插件）
    ↓ 共用
  通用工具（Logger, ErrorHandler, Serializer）
]
```
