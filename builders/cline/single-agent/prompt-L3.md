# Cline 创建与规划 L3 任务 — Prompt 模板（单 Agent 模式）

> 将以下 prompt 复制到 Cline 对话中使用。
> 使用前替换 `[任务编号]`、`[任务描述]` 和 `[项目目录]` 为实际值。
>
> **前置条件**: 已用 `prompt-L1a.md`/`prompt-L1b.md` 和 `prompt-L2.md` 完成 L1/L2 文档生成。
> **本文件范围**: 创建新任务文件、AI 分析与规划、生成验收问题与测试用例。

---

## Prompt

```markdown
# 任务：创建并规划一个新的开发任务（L3）

## 背景
我需要在 AI 上下文文档中的 **L3 任务层** 创建一个新任务。

文件结构：
```
.ai/L3-tasks/
├── board.md              ← 任务看板（所有任务状态一览）
├── _task-template.md     ← 任务模板（复制来创建新任务）
├── TASK-XXX-描述.md      ← 各任务详情文件
└── decision-log.md       ← 技术决策记录
```

## 我的任务

**编号**: TASK-[任务编号]
**描述**: [任务描述 — 用自然语言写，越详细越好]

附加线索（如果有）：
- [错误日志 / 截图 / issue 链接 / 相关文件路径]

## 你的工作步骤

### Step 1: 收集上下文

先读取项目导航和已有任务状态：

```bash
# 读取项目索引（了解项目结构和功能）
cat [项目目录]/.ai/L1-codebase-map/overview.md

# 读取任务看板（了解现有任务）
cat [项目目录]/.ai/L3-tasks/board.md

# 读取任务模板
cat [项目目录]/.ai/L3-tasks/_task-template.md
```

根据我的任务描述，从 overview.md 的功能索引定位涉及的功能和模块，然后按需加载：

```bash
# 如果涉及已有功能 — 加载功能文档
cat [项目目录]/.ai/L1-codebase-map/features/[功能名]/README.md

# 如果涉及特定模块 — 加载模块规则
cat [项目目录]/.ai/L2-rules/[模块名].md

# 如果涉及全局规则
cat [项目目录]/.ai/L2-rules/global.md
```

### Step 2: 创建任务文件

复制 `_task-template.md`，命名为 `TASK-[任务编号]-简短描述.md`。

填写「任务输入」部分 — 直接搬运我上面写的任务描述。

### Step 3: AI 填写计划

根据 Step 1 收集的上下文，填写「AI 计划」部分：

#### 3a: 概要
- **目标**: 一句话概括要达成什么
- **分析**: 涉及哪些功能/模块，存在什么风险，需要注意什么
- **范围**: 列出涉及的模块和关键文件路径

#### 3b: 验收问题（关键！）
主动提出 3-5 个需要我确认的问题。好的验收问题：
- ✅ 涉及业务决策："导出数据量超过 10 万条时，是分页还是异步下载？"
- ✅ 涉及边界情况："并发修改同一记录时，是报错还是最后写入者胜出？"
- ✅ 涉及兼容性："旧的 API 调用者需要兼容吗？还是可以直接 break？"
- ❌ 不要问技术实现细节（那是你决定的）
- ❌ 不要问能通过读代码就知道的事

**提完问题后停下来，等我回答。**

#### 3c: 生成测试用例
根据我的答案，生成具体的可验证测试用例。每个测试用例：
- 描述清楚输入、操作、预期结果
- 可以直接转化为自动化测试或手动验证步骤

#### 3d: 执行步骤
写出具体到文件级的执行步骤：
- 每步说明要改哪个文件、改什么
- 每步有对应的验证命令
- 标注风险点

#### 3e: 约束与风险
- ❌ 禁止做什么
- ⚠️ 风险点及应对方案
- 🔙 回退方案

### Step 4: 更新看板

在 `board.md` 的活跃任务表中添加一行：

```markdown
| TASK-[编号] | [任务简述] | 📋 open | — | → TASK-[编号]-描述.md |
```

### Step 5: 等待确认

**不要开始执行！** 把完整的计划和测试用例展示给我，等我确认后再开始。

确认后：
1. 将 board.md 状态改为 🔨 ongoing
2. 更新 L4 active-session.md 指向该任务
3. 开始执行 Step 1

## 输出格式

完成后应该有：
1. ✅ 新建 `TASK-[编号]-描述.md` — 包含任务输入 + AI 计划 + 验收问题（等待回答）
2. ✅ `board.md` 已添加该任务（📋 open 状态）
3. ⏸️ 等待我回答验收问题，然后补充测试用例
```

---

## 使用流程总结

```
1. 复制上方 Prompt，填入 [任务编号] 和 [任务描述]
2. AI 创建任务文件 + 写出计划 + 提出验收问题
3. 你回答验收问题
4. AI 生成测试用例，等你确认
5. 你确认 → AI 改状态为 ongoing，开始执行
6. 每次对话结束 → AI 更新 L4 active-session.md
7. 代码完成 → 状态改为 done
8. 测试通过 + 你确认 → 删除任务文件
```
